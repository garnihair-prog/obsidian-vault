# 一人経営の美容室のホームページ制作リサーチ

> [!note] このノートについて
> 「NotebookLMで収集してObsidianに保存」という依頼を受けたが、NotebookLMはGoogleアカウントでの対話操作が必要なツールで、このセッションからは直接操作できなかった。代わりにWeb検索で一次情報を収集し、要点を整理してこのノートにまとめた。

## 1. 一人経営サロンならではの訴求ポイント

- **完全予約制**：一人経営では同時対応できる人数が限られるため、完全予約制にすることで当日ドタキャンのリスクを減らし、来店ごとに十分な時間を確保できる。
- **オーナー＝サロンそのもの**：スタッフがいない分すべての決定権が自分にあり、「オーナー＝ブランド」という一体感が強い個人ブランドをつくる武器になる。
- **プライベート/個室空間**：周りの目を気にせず過ごせる空間であることは、一人サロンの重要な差別化ポイントとして打ち出しやすい。
- カウンセリングから仕上げまで同一人物が担当する一貫性も、安心感の訴求として有効。

## 2. ホームページに必須のコンテンツ

最低限、以下が揃っていることが望ましいとされる（複数の制作会社記事で共通）。

- **トップ（About／コンセプト）**：どんなサロンか、誰が担当するか
- **メニュー・料金**：カット・カラー・パーマなどを単体／セットの両方でわかりやすく明記。初めての人ほど「料金がわからない不安」が離脱要因になる
- **スタイリスト紹介**：一人サロンでは特に「誰が担当するか」の顔出し・人柄紹介が信頼構築に直結する
- **アクセス・営業時間・定休日**：地図、駐車場情報、不定休の案内
- **予約導線（CTA）**：電話・予約システムへのリンクをページ上部から一貫して配置
- （余力があれば）**よくある質問（FAQ）**、**ブログ／お知らせ**、**Before/After・スタイル実績ギャラリー**

## 3. 情報設計・導線のポイント

- ファーストビュー直下に主要な導線（メニュー・アクセス・予約）をカード化し、初見のユーザーが最短で情報にたどり着けるようにする。
- 情報は「信頼 → 理解 → 比較 → 行動」の順で並べると、行動（予約）へのハードルが下がる。
  - 信頼：コンセプト・こだわり・スタイリスト紹介
  - 理解：メニュー・料金
  - 比較：アクセス・営業時間・プラス料金など詳細情報
  - 行動：予約ボタン・電話・QRコード
- 抜け感のある写真を大きく見せつつ、価格と予約ボタンの可読性を優先する「最短設計」が有効（＝情報を詰め込みすぎない）。

## 4. デザイン面のポイント（海外事例も含む）

- 本物の施術写真・店内写真・スタイリストの顔写真を使う。ストック写真より、実際の作品・空間の方が信頼構築が速い。
- Before/Afterのスタイル実績ギャラリーは特に効果的。
- スマホでの閲覧・予約導線を最優先に設計する（モバイル最適化必須）。
- 派手なアニメーションより「わかりやすさ」が予約数に直結する。整理されたメニュー表・軽量な画像・シンプルな予約導線が最重要。

## 5. 集客・運用面

- Googleビジネスプロフィールへの登録は必須級（検索・マップ経由の来店が多いため）。
- SNSアカウント（Instagramなど）とホームページの相互リンク。
- 予約システム（電話だけでなくオンライン予約）を用意し、ホームページから迷わず遷移できるようにする。
- オープン前からブログ等でコンテンツを積み上げておくと、開業後の集客が立ち上がりやすいという事例もある。
- 公開後も「最新の情報を簡単に更新できる」仕組みにしておくことが重要（メニュー改定・臨時休業など）。

## 6. GARNI HAIRの現状ページへの当てはめ

`/garni-hair`（my-schedule-appリポジトリ内）に既に実装済みのもの：

- [x] コンセプト（丁寧なカウンセリング・確かな技術・アフターケア・おひとりの空間）
- [x] 完全予約制・個室空間・プライベートサロンのバッジ
- [x] メニュー・料金（カテゴリー別、学割表示、プラス料金の別セクション）
- [x] スタイリスト紹介（店長 GARNI、一人で対応する旨を明記）
- [x] 営業時間・定休日・不定休の案内（予約アプリへの誘導）
- [x] アクセス（住所・地図・駐車場）
- [x] 電話番号（tel:リンク）
- [x] 予約導線（ボタン3箇所＋QRコード）
